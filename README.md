# Java Fundamentals ☕

A collection of Java programming exercises developed during my university studies to practice programming fundamentals, logical thinking, and problem-solving.

## 📚 About the Project

This repository contains 15 Java exercises covering essential programming concepts, from basic input and output to arrays, loops, conditional statements, and input validation.

The goal of these exercises is to strengthen my understanding of Java and build a solid foundation for more advanced programming projects.

## Exercises

| # | Exercise | Description |
|---|---|---|
| 01 | Age Classification | Classifies a person as an adult or a minor based on their age. |
| 02 | Temperature Conversion | Converts a temperature from Celsius to Fahrenheit. |
| 03 | Customer Service Menu | Simulates a customer service menu with different options. |
| 04 | Multiplication Table | Generates the multiplication table for a given number. |
| 05 | Attempt Counter | Simulates code verification with a limited number of attempts. |
| 06 | Grade Validation | Validates a grade within the range of 0 to 10. |
| 07 | Weekly Temperatures | Calculates the average temperature and counts days above 25 degrees. |
| 08 | Guess the Number | A number-guessing game using randomly generated numbers. |
| 09 | Class Grades | Stores student grades and calculates individual averages. |
| 10 | Age Input Validation | Validates age input using exception handling. |
| 11 | Calculator with Division Validation | Performs basic arithmetic operations and handles division by zero. |
| 12 | Product Inventory Search | Searches for a product code in an array. |
| 13 | Room Occupancy Control | Manages room seats, allowing users to occupy and release seats. |
| 14 | Participant Draw | Randomly selects three participants without repeating selected names. |
| 15 | Grade Management System | Calculates student averages, identifies passing students, and generates class reports. |

## Technologies and Concepts

- **Language:** Java
- **Input and Output:** `Scanner`, `System.out.println()`
- **Conditional Statements:** `if`, `else`, `switch`
- **Loops:** `for`, `while`, `do-while`
- **Arrays:** One-dimensional and multidimensional arrays
- **Random Numbers:** `Random`
- **Exception Handling:** `try-catch`
- **Input Validation:** Checking user input and valid grade ranges
- **Mathematical Operations:** Calculations, averages, and temperature conversion

##  Learning Objectives

Through these exercises, I am developing my skills in:

- Understanding Java syntax and program structure.
- Applying conditional logic and repetition structures.
- Working with arrays and collections of data.
- Validating user input and handling exceptions.
- Developing algorithms to solve practical problems.
- Organizing code and improving programming logic.
